# Python Proyectos Educacionales

Repositorio con ejercicios y proyectos de Python desarrollados durante mi aprendizaje, organizados por tema. Cubre progresivamente desde fundamentos (variables, estructuras de datos) hasta temas avanzados como programación orientada a objetos, programación funcional, concurrencia, patrones de diseño, persistencia con bases de datos y proyectos integradores.

## 🗺️ Roadmap de temas

### 1. Fundamentos
- [ ] Variables y tipos de datos
- [ ] Operadores (aritméticos, lógicos, relacionales)
- [ ] Estructuras condicionales (if, elif, else, match-case)
- [ ] Bucles (for, while)
- [ ] Listas y tuplas
- [ ] Funciones (parámetros, *args, **kwargs, retorno)
- [ ] Input/output por consola

### 2. Estructuras de datos
- [ ] Diccionarios
- [ ] Sets
- [ ] Comprensiones (list, dict, set comprehensions)
- [ ] Slicing avanzado

### 3. Programación Orientada a Objetos (POO)
- [ ] Clases y objetos
- [ ] Atributos, métodos y __init__
- [ ] Encapsulamiento (propiedades, @property)
- [ ] Herencia
- [ ] Polimorfismo
- [ ] Clases abstractas (module abc)
- [ ] Dataclasses
- [ ] Métodos mágicos / dunder (__str__, __eq__, __len__, etc.)

### 4. Manejo de errores
- [ ] Try-except-finally
- [ ] Excepciones personalizadas
- [ ] Context managers (with, __enter__/__exit__)

### 5. Programación funcional
- [ ] Funciones lambda
- [ ] map, filter, reduce
- [ ] Decoradores
- [ ] Generadores e iteradores

### 6. Módulos y paquetes
- [ ] Imports y módulos propios
- [ ] Entornos virtuales y pip

### 7. Entrada/Salida (I/O)
- [ ] Lectura/escritura de archivos de texto
- [ ] JSON y CSV
- [ ] Manejo de rutas con pathlib

### 8. Concurrencia
- [ ] Threading
- [ ] Multiprocessing
- [ ] Asyncio

### 9. Patrones de diseño
- [ ] Singleton
- [ ] Factory
- [ ] Observer
- [ ] Strategy
- [ ] Decorator

### 10. Persistencia y bases de datos
- [ ] SQLite básico (sqlite3)
- [ ] CRUD desde consola conectado a BD
- [ ] ORM con SQLAlchemy

### 11. Testing
- [ ] unittest
- [ ] pytest

### 12. Proyectos integradores
- [ ] CRUD completo en consola
- [ ] API REST básica (Flask/FastAPI)
- [ ] Proyecto con Poetry

## 🛠️ Tecnologías

- Python 3.x
- pip / venv (o Poetry, si aplica)

### Cómo clonar este repositorio

```
git clone https://github.com/tu-usuario/Python-Proyectos-Educacionales.git
cd Python-Proyectos-Educacionales
```

Luego puedes entrar a la carpeta del ejercicio que quieras revisar o ejecutar, por ejemplo:

```
cd 01-Fundamentos/001-variables-tipos-datos
python main.py
```
